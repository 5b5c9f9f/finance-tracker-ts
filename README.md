# 💸 FinFlow — SaaS-платформа для управления личными финансами

Полнофункциональное многостраничное веб-приложение для учета личных доходов и расходов, визуализации аналитики и контроля бюджета.

## 🛠 Технологический стек

- **Frontend:** React 19, TypeScript
- **Маршрутизация:** React Router DOM
- **Визуализация данных:** Recharts
- **Иконки:** Lucide React
- **Стилизация:** CSS Modules (изолированные стили компонентов)
- **Сборка:** Vite

## 📂 Архитектура проекта

```text
src/
├── components/                 # Переиспользуемые компоненты интерфейса
│   ├── BalanceCard.tsx         # Карточка сводки баланса, доходов и расходов
│   ├── CategoryChart.tsx       # Кольцевая диаграмма трат по категориям (Recharts)
│   ├── Header.tsx              # Адаптивная шапка с логотипом и навигацией профиля
│   ├── ProtectedRoute.tsx      # HOC-компонент для защиты приватных маршрутов
│   ├── TransactionFilters.tsx  # Панель вкладок фильтрации и строка поиска
│   ├── TransactionForm.tsx     # Управляемая форма добавления новой операции
│   └── TransactionList.tsx     # Список операций с форматированием и удалением
├── context/                    # Глобальное состояние приложения
│   └── AuthContext.tsx         # Провайдер авторизации и кастомный хук useAuth
├── pages/                      # Страницы приложения (Routes)
│   ├── HomePage.tsx            # Главная страница (Landing Page)
│   ├── LoginPage.tsx           # Страница входа в аккаунт
│   ├── RegisterPage.tsx        # Страница регистрации нового пользователя
│   └── DashboardPage.tsx       # Приватный личный кабинет с аналитикой
├── types/                      # Строгие TypeScript-интерфейсы и типы
│   ├── auth.ts                 # Типы пользователя (User)
│   └── finance.ts              # Типы транзакций (Transaction, TransactionType)
├── App.tsx                     # Конфигурация роутинга и провайдеров
└── main.tsx                    # Точка входа приложения
```

## 🚀 Локальный запуск

1. **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com
    ```

2. **Установите зависимости:**

    ```bash
    cd finance-tracker-ts
    npm install
    ```

3. **Запустите сервер разработки:**
    ```bash
    npm run dev
    ```
